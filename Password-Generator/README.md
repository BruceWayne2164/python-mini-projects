# Password Generator 🔐

A simple Python-based password generator that creates random passwords based on the length specified by the user.

## Features

- Generate random passwords
- User-defined password length
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Generates a new random password each time

## Technologies Used

- Python
- `random` module
- `string` module

## Concepts Used

- Variables
- User Input
- Loops
- Strings
- Modules
- Randomization
- String Manipulation

## How to Run

Run the following command in your terminal:

```bash
python password_generator.py
